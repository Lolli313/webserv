🔧 HTTP Methods Test

Test different HTTP methods and their restrictions.

What this tests:

  • GET - Retrieve resources
  • POST - Submit data to server
  • DELETE - Remove resources
  • HEAD - Get headers only (no body)
  • Method restrictions per route (405 Method Not Allowed)
  • Unknown method handling (501 Not Implemented)
