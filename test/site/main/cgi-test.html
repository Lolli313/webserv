⚙️ CGI Script Execution Test

Test the webserver's ability to execute CGI scripts (Python, PHP, etc.).

What this tests:

  • CGI script execution (Python/PHP)
  • Environment variables (REQUEST_METHOD, QUERY_STRING, etc.)
  • GET request with query parameters
  • POST request with body data
  • Content-Type header parsing
  • Script output capture and return
  • Error handling for script failures

🐍 Python CGI - GET Request

Test a simple Python script that echoes environment variables.

🐍 Python CGI - POST Request

Test POST data handling with Python CGI.

🐘 PHP CGI (if available)

Test PHP script execution.

📂 CWD & Relative Path Test

Tests if the CGI script runs in its own directory (required for relative file access).

❓ Query String Test

Test CGI with query parameters: ?name=value&key=data

✅ Expected Behavior:

  • Scripts should execute without crashing the server
  • Environment variables should be set correctly
  • POST data should be passed via stdin
  • Script output should be returned as HTTP response
  • Errors in scripts should return 500 status code
  • CWD should be the script's directory (allowing relative file access)
