🌐 Multiple Ports Test

Test the webserver's ability to listen on multiple ports simultaneously.

What this tests:

  • Server listens on multiple ports (3000, 3001, 3002, etc.)
  • Each port serves different content/configuration
  • Different root directories per port
  • Independent route configurations
  • Simultaneous connections on different ports

🔧 Configuration Example:

Each port should have its own server block in the config:

server {
    listen 3000
    root test/test_suite/
    ...
}

server {
    listen 3001
    root test/site/static/
    ...
}

server {
    listen 3002
    root test/cgi-bin/
    ...
}

💡 Testing with curl:

# Test all ports
curl -I http://localhost:3000/
curl -I http://localhost:3001/
curl -I http://localhost:3002/

# Verify different content
curl http://localhost:3000/ | head
curl http://localhost:3001/ | head
curl http://localhost:3002/ | head

# Test simultaneous connections
curl http://localhost:3000/ & curl http://localhost:3001/ & curl http://localhost:3002/

✅ Expected Behavior:

  • All configured ports respond simultaneously
  • Each port serves different content based on its root directory
  • Routes and configurations are independent per port
  • Server handles connections on all ports without blocking
  • Port-specific settings (max_body_size, etc.) work correctly
