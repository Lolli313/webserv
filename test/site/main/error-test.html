🚨 Error Handling Test

Test custom error pages and proper HTTP status codes.

What this tests:

  • Custom error page serving
  • Correct HTTP status codes
  • Error page fallbacks
  • Server doesn't crash on errors
  • Proper error logging
404
Not Found

Resource doesn't exist

405
Method Not Allowed

Method not supported

413
Payload Too Large

Body exceeds limit

500
Internal Server Error

Broken CGI script

💡 Testing with curl:

# Test 404
curl -I http://localhost:3000/nonexistent-file

# Test 405 (DELETE on GET-only route)
curl -X DELETE http://localhost:3000/

# Test 413 (create large body with dd)
dd if=/dev/zero bs=1M count=11 | curl -X POST --data-binary @- http://localhost:3000/uploads
